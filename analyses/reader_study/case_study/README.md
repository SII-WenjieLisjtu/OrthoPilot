## 💡 关键洞察

### 为什么CHEESE能做对而其他模型做错？

1. **骨科专科知识**：CHEESE基于瑞金医院18万患者数据训练
2. **临床经验编码**：通过强化学习获得跨阶段决策能力
3. **双证据范式**：院内信息 + 院外知识的融合
4. **工具增强**：Tool Plaza提供的专科工具支持

### 这些案例的临床意义

- 罕见病诊断（如骨化性肌炎）
- 复杂鉴别诊断
- 需要结合病史、体征、影像的综合判断
- 容易被误诊或漏诊的场景
